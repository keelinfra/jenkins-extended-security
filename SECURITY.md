# Security

## Reporting a problem

- **A vulnerability in Jenkins itself**, including one these patches don't cover yet: report it to the Jenkins security team as described at <https://www.jenkins.io/security/reporting/>. Don't report it here first.
- **A problem these patches cause**, such as a backport that is incomplete, wrong, or opens a new hole that stock Jenkins doesn't have: email hello@keelinfra.io. Please don't open a public issue for it.

## What is covered

Only the Jenkins core, Remoting and Stapler fixes listed in [COVERAGE.md](COVERAGE.md). Plugins are not covered.

These builds are not part of Jenkins security advisories or CVE assignments, and the Jenkins security team does not review them.
